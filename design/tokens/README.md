# Athena design tokens

Adapted from `reference/design/tokens` (Naviator console / site palette).  
Athena ideation mockups under `design/` **must** use these tokens — do not invent one-off hex in screens without registering here.

| Layer | Use |
|-------|-----|
| `--pb-*` / console | Main Athena cockpit (light workbench) |
| `--site-*` | Dark control-web / connection pages / bot card previews |
| Semantic | success / warn / danger / info |
